# Consulta de CEP em Python 📍

Um projeto simples e funcional que utiliza a biblioteca `requests` para buscar informações de endereço de qualquer CEP brasileiro através da API pública do ViaCEP.

## ✨ Funcionalidades
- Busca automática de Logradouro e Localidade (Rua e cidade).
- Interface via terminal bem simples.
- Tratamento básico de dicionários em Python.

## 🚀 Tecnologias Utilizadas
- **Python 3.14**
- **Biblioteca Requests**.
- **ViaCEP API**: Serviço gratuito de busca de CEP.

## 🛠️ Como rodar o projeto
1. Clone o repositório:
   `git clone https://github.com/Rian-zin/consulta-cep-python.git`
2. Instale a biblioteca necessária:
   `pip install requests`
3. Execute o script:
   `python consulta-cep.py`
